# UDトーク Web公開 → OBS テキスト ブリッジ

UDトークの「ウェブで公開」ページから会話を取得し、OBSの既存テキストソースを更新する最小アプリです。ゆかりねっとコネクターNEO、UDトーク文字入力、ブラウザ操作は必要ありません。

公開ページが会話表示に使う公式のWeb APIを定期取得し、**新しく確定した発話だけ**をOBSへ転送します。過去ログは起動時に表示しません。

## 必要なもの

- Node.js 22以降
- OBS Studio 28以降（OBS WebSocketサーバーを有効化）
- UDトークで「ウェブで公開」済みのトーク
- OBS内に作成済みのテキストソース

## セットアップ

1. UDトークの「トークを公開する」画面で「ウェブで公開」を選び、発行された `https://live.udtalk.jp/...` のURLをコピーします。
2. OBSの「ツール」→「WebSocketサーバー設定」でサーバーを有効にし、ポート（通常 `4455`）とパスワードを確認します。
3. OBSでテキストソースを作成します。例: `字幕`。
4. `.env.example` をコピーして `.env` を作成します。
5. `.env` を開き、OBSの接続情報、テキストソース名、UDトークの公開URLを設定します。

```dotenv
OBS_PASSWORD="OBSで設定したパスワード"
OBS_INPUT_NAME=字幕
OBS_URL="ws://127.0.0.1:4455"
UDTALK_PUBLIC_URL="https://live.udtalk.jp/ここに64文字のID"
POLL_MS=500
```

`OBS_PASSWORD`、`OBS_INPUT_NAME`、`UDTALK_PUBLIC_URL` は必須です。パスワードは必ず引用符で囲んでください。`#` や空白を含んでも正しく読み込めます。

## 起動

```bash
npm start
```

次の2行が表示されれば接続完了です。

```text
OBS WebSocketの認証が完了しました。
UDトークWeb公開に接続しました。新しい確定発話をOBSへ転送します。
```

以後、UDトークのWeb公開画面に新しく確定表示された発話がOBSテキストソースへ転送されます。

## 注意

- Web公開URLは閲覧用のURLです。パスコード付きの公開ページには現在対応していません。
- URLを知っている人が閲覧できるトークなので、URLの取り扱いに注意してください。
- `POLL_MS` は会話の取得間隔です。既定の `500`（毎秒2回）を推奨します。通信が不安定な場合は `1000` に上げてください。

`.env` はGitの管理対象外なので、公開URLやパスワードはコミットされません。
