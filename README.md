# UDトーク → OBS テキスト ブリッジ

UDトークの会話をOBSの既存テキストソースに表示する、最小のローカルアプリです。ゆかりねっとコネクターNEOは使用しません。

UDトークの会話プロトコルは公開されていないため、公式の「UDトーク文字入力」を使って会話を入力欄へ送ります。このアプリはその入力をOBS WebSocket v5へ転送するだけです。

## 必要なもの

- Node.js 22以降
- OBS Studio 28以降（OBS WebSocketサーバーを有効化）
- UDトーク
- 公式の「UDトーク文字入力」（WindowsまたはMac）
- OBS内に作成済みのテキストソース

## セットアップ

1. OBSの「ツール」→「WebSocketサーバー設定」でサーバーを有効にし、ポート（通常 `4455`）とパスワードを確認します。
2. OBSでテキストソースを作成します。例: `字幕`。
3. `.env.example` をコピーして `.env` を作成します。

PowerShell:

```powershell
Copy-Item .env.example .env
```

Linux / macOS:

```bash
cp .env.example .env
```

4. `.env` を開き、OBSの接続情報とテキストソース名を設定します。

```dotenv
OBS_PASSWORD="OBSで設定したパスワード"
OBS_INPUT_NAME=字幕
OBS_URL="ws://127.0.0.1:4455"
INPUT_PORT=3030
```

パスワードは必ず引用符で囲んでください。`#` や空白を含んでも正しく読み込めます。

## 使い方

1. ブリッジを起動します。

```bash
npm start
```

`OBS WebSocketの認証が完了しました。` と `UDトーク文字入力ページ: http://localhost:3030` が表示されます。

2. 同じPCでブラウザから `http://localhost:3030` を開き、表示された入力欄を一度クリックします。以後は入力欄を閉じたり別の入力欄へ移動したりしないでください。
3. 「UDトーク文字入力」を起動して「トークを公開」を選択します。表示されたQRコードをUDトークアプリで読み取り、そのトークに参加します。
4. UDトークで認識・確定した文章がブラウザの入力欄を通じてOBSのテキストソースへ送られます。

ブラウザが別のPCにある場合は、ブリッジを起動したPCのIPアドレスを使います。たとえばブリッジPCが `192.168.10.10` なら `http://192.168.10.10:3030` を開きます。信頼できるネットワーク内だけで使用してください。

## 設定

```text
OBS_INPUT_NAME             OBSのテキストソース名（必須）
OBS_PASSWORD               OBS WebSocketパスワード
OBS_URL                    既定: ws://127.0.0.1:4455
INPUT_PORT                 入力ページのポート。既定: 3030
RECONNECT_MS               OBS再接続間隔（ミリ秒）。既定: 2000
```

`.env` はGitの管理対象外なので、パスワードはコミットされません。設定を一時的に上書きする場合は、同名の環境変数または `--input-name`、`--obs-password`、`--obs-url`、`--input-port` を使えます。
