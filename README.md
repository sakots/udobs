# UDトークの会話をOBSに表示する

UDトークで認識した会話を、OBSのテキストソースに字幕として表示するアプリです。WindowsとLinuxで動作します。

```text
UDトークのWeb公開 → このアプリ → OBS WebSocket → OBSテキストソース
```

UDトークのWeb公開ページから、新しく確定した発話を取得します。起動前の過去ログは表示しません。ゆかりねっとコネクターNEOやUDトーク文字入力を用意する必要はありません。

開発にはCodexを使用しています。

## 必要なもの

- Node.js 22以降
- pnpm
- OBS Studio 28以降
- UDトークで「ウェブで公開」を有効にしたトーク

## 初回の準備

### UDトークとOBSを準備する

UDトークの「トークを公開する」画面で「ウェブで公開」を選んでください。発行された `https://live.udtalk.jp/...` のURLを設定に使います。

OBSでは「ツール」→「WebSocketサーバー設定」を開き、サーバーを有効にしてください。ポート番号とパスワードも確認します。通常のポート番号は `4455` です。

続いて、OBSにテキストソースを作成してください。以下の例ではソース名を `字幕` とします。

### アプリの設定を保存する

プロジェクトのフォルダで依存パッケージをインストールしてください。

```bash
pnpm install
```

[.env.example](.env.example)をコピーして、同じフォルダに `.env` を作成します。

WindowsのPowerShellで使うコマンドです。

```powershell
Copy-Item .env.example .env
```

Linuxで使うコマンドです。

```bash
cp .env.example .env
```

`.env` を開き、パスワード、ソース名、Web公開URLを実際の値に置き換えてください。

```dotenv
OBS_PASSWORD="OBSで設定したパスワード"
OBS_INPUT_NAME=字幕
# ひとつ前の字幕も表示する場合に設定
OBS_PREVIOUS_INPUT_NAME=
OBS_URL="ws://127.0.0.1:4455"
UDTALK_PUBLIC_URL="https://live.udtalk.jp/ここに64文字のID"
POLL_MS=500
MAX_CHARS_PER_LINE=24
```

`OBS_INPUT_NAME` にはOBSのソース名、`UDTALK_PUBLIC_URL` には発行されたURLを指定してください。OBSの認証が有効な場合は `OBS_PASSWORD` も必要です。パスワードを引用符で囲むと、`#` や空白を含む値も読み込めます。

OBSが別のPCで動いている場合は、`OBS_URL` の `127.0.0.1` をそのPCのIPアドレスに置き換えます。

### ひとつ前の発話も表示する

OBSにもう1つテキストソースを作り、`字幕_ひとつ前` などの別名を付けてください。その名前を `.env` の `OBS_PREVIOUS_INPUT_NAME` に指定します。

```dotenv
OBS_INPUT_NAME=字幕
OBS_PREVIOUS_INPUT_NAME=字幕_ひとつ前
```

新しい字幕が届くと、直前の字幕をこのソースに表示します。最初の発話では空欄です。不要なら `OBS_PREVIOUS_INPUT_NAME` は空欄のままにしてください。

## 起動と終了

設定を保存したら、プロジェクトのフォルダで起動してください。

```bash
pnpm start
```

次の2行が表示されれば接続完了です。

```text
OBS WebSocketの認証が完了しました。
UDトークWeb公開に接続しました。新しい確定発話をOBSへ転送します。
```

UDトークで話すと、Web公開に届いた確定発話をOBSの字幕として表示します。

終了するにはターミナルで `Ctrl+C` を押してください。Windowsでは `Ctrl+Break` も使えます。設定を変更した場合は、アプリを再起動すると反映されます。

pnpm経由では、中断時に `ELIFECYCLE` と表示されることがあります。pnpmの終了コード表示を避けたい場合は、次のコマンドで起動してください。どちらの起動方法でもTypeScriptをビルドします。

```bash
node scripts/start.mjs
```

## ログの保存

アプリのログは画面に表示すると同時に、プロジェクトの `logs/` フォルダへUTF-8のテキストで保存します。起動ごとに `udobs-日時-プロセスID.log` を作り、起動時に保存先を表示します。各行の日時はUTCです。

字幕本文、接続・切断、警告、エラー、終了処理のログが保存されます。`Ctrl+C` の直前まで保存するため、書き込みはその都度行います。pnpm自身の `ELIFECYCLE` 表示や、アプリ起動前のビルド出力は含まれません。

ログには会話本文や接続先が含まれます。共有する前に内容を確認してください。`logs/` はGitの管理対象外です。ログは自動削除しないので、不要になったファイルは削除してください。

## 字幕の表示を調整する

`.env` の `POLL_MS` で会話を取得する間隔を指定します。テンプレートの設定は `500` ミリ秒です。通信が不安定な場合は `1000` に上げてください。

`MAX_CHARS_PER_LINE` は自動改行する文字数です。通常は `24` を使います。字幕がOBSの表示幅に収まらない場合は `18` などに下げてください。

## 制限と公開URLの扱い

パスコード付きのWeb公開ページには対応していません。また、UDトークのWeb公開に届かなかった発話は、このアプリでも取得できません。

Web公開URLを知っている人はトークを閲覧できます。URLやOBSのパスワードを他人に共有しないようにしてください。

`.env` はGitの管理対象外なので、公開URLやパスワードはコミットされません。

## 開発時の確認

実装はTypeScriptです。次のコマンドで `dist/` にコンパイルしてからテストを実行します。

```bash
pnpm test
```
